# Biodiversity Monitoring Using Acoustic Data

## Overview

This project demonstrates how acoustic data can be used to monitor biodiversity across different environments. By analyzing sound recordings from various locations, the system helps identify species presence and assess biodiversity patterns in a non-invasive and efficient way.

The dataset used in this project is **synthetic** and created for learning, research, and demonstration purposes.

## Project Objectives

* Simulate biodiversity monitoring using acoustic signals
* Classify species based on sound characteristics
* Store and manage acoustic monitoring data
* Export processed data into Excel format for analysis and reporting

## Dataset Description

The dataset represents acoustic recordings collected from different ecological zones.

### Features

* **Recording_ID**: Unique identifier for each audio recording
* **Location**: Area where the sound was recorded
* **Species**: Detected species category (Bird, Frog, Insect)
* **Sound_Frequency_Hz**: Dominant frequency of the sound
* **Sound_Duration_sec**: Duration of the sound event
* **Detection_Confidence**: Probability score indicating detection reliability

## Methodology

1. Generate synthetic acoustic biodiversity data
2. Organize data into structured format
3. Analyze sound features for species identification
4. Export the dataset to Excel for easy visualization and further analysis
